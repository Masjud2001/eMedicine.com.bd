# eMedicine BD - Project Overview

eMedicine BD is a modern, responsive, and conversion-focused e-commerce pharmacy platform for Bangladesh. It provides a professional, safe, and fast digital healthcare experience, allowing users to order genuine medicines, upload prescriptions, and consult with doctors online.

---

## 🚀 Key Features

### 1. **Modern Homepage**
- **Hero Section**: Strong medical branding with conversion-focused CTAs (Upload Prescription, Order Medicine).
- **Service Highlights**: Dynamic trust indicators for 10K+ Medicines, Fast Delivery, Top Doctors, and 100% Secure operations.
- **Top Categories**: Grid view for easy access to various healthcare segments (OTC, Prescription, Baby Care, etc.).
- **Flash Deals & Bestsellers**: Swiper-based carousels showcasing high-demand products.

### 2. **Medicine Marketplace**
- **Shop & Filter**: Sidebar with advanced filters for categories, pharma brands (Beximco, Square, etc.), price ranges, and prescription requirements.
- **Product Details**: High-definition gallery, unit/total price calculations, dosage warnings, and related health needs.

### 3. **Prescription Management**
- **Seamless Upload**: Drag-and-drop prescription submission with secure verification.
- **Auto-Refill**: Easy reordering system based on previous Order IDs.

### 4. **Tele-Health & Services**
- **Doctor Consultation**: A directory of verified specialists for video/chat consultations.
- **Live Tracking**: Real-time logistics tracking page with progress steps and rider info.

### 5. **Checkout & Logistics**
- **Local Payments**: Support for bKash, Nagad, and Cash on Delivery.
- **Dynamic Cart**: Professional cart management with live subtotal/total calculations.

### 6. **Trust & Support**
- **WhatsApp Integration**: Floating pharmacist chat button on every page.
- **DGDA Licensing**: Trust badges and verified vendor indicators.

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Components**: Radix UI
- **Carousels/Sliders**: Swiper.js, Embla Carousel
- **Forms & Validation**: React Hook Form, Zod
- **Notifications**: React Hot Toast
